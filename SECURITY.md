# Security policy

## Supported versions

Security fixes target the latest released version of Plainsay. Before
reporting, confirm that the issue still occurs on the newest release when it is
safe to do so.

## Report a vulnerability privately

Do not include a vulnerability, exploit, credential, private recording, or
transcript in a public issue or discussion.

Email [hi@plainsay.app](mailto:hi@plainsay.app) with the subject
`[SECURITY] Plainsay vulnerability`. Include:

- the affected version and macOS version;
- whether the issue concerns the Mac app, update channel, website, or Cloud;
- reproduction steps or a minimal proof of concept;
- the expected impact and any known mitigations;
- a safe way to contact you for follow-up.

Sensitive attachments should not be sent until a secure transfer method has
been agreed. Receipt will be acknowledged as soon as practical, followed by
triage and a coordinated disclosure plan appropriate to the issue.

## Scope notes

The Mac app is MIT-licensed and can be audited in this repository. Plainsay
Cloud is a separate hosted service, but security reports about it are still in
scope. Reports about a third-party model or API should normally go to that
provider unless Plainsay's integration creates the vulnerability.
