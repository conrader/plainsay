여기서 신뢰는 주장이 아니라 코드를 직접 읽을 수 있다는 뜻입니다. Plainsay Mac 클라이언트 소스는 MIT 라이선스로 공개되어 있습니다. 이미 MIT로 공개된 각 버전은 자유롭게 포크하고 수정하고 빌드할 수 있으며, 타사 구성요소와 모델에는 별도 라이선스가 적용됩니다.

공개된 부분

Plainsay Mac 클라이언트 소스에는 필사 및 Polishing 통합, HUD, 설정, 설정 도우미가 포함됩니다. 타사 구성요소와 모델에는 별도 라이선스가 적용됩니다. Mac 클라이언트는 분석이나 원격 측정을 전송하지 않습니다. 서명된 업데이트 확인은 기본적으로 api.plainsay.app에 연결하며 설정에서 끌 수 있습니다. 선택적 Cloud는 유료 서비스 운영에 필요한 계정, 구독, 사용량 메타데이터를 기록합니다.

공개되지 않은 부분

유료 Cloud 요금제의 백엔드는 Stripe를 통해 구독 상태를 관리하고, 서비스 제공사 자격 증명을 보관하며, 유료 서비스에 필요한 계정, 구독, 사용량 메타데이터를 기록합니다. Plainsay Mac 클라이언트 소스는 공개되어 있지만 선택적 Cloud 서비스는 공개되어 있지 않습니다.

기본적으로 Polishing은 표현, 의미, 어조, 언어를 보존합니다. 중요한 글은 확인하세요. 자동 번역을 켜면 대신 모든 받아쓰기 결과를 Plainsay 메뉴에서 선택한 대상 언어로 출력합니다. 제공자는 교체할 수 있으며(Gemini, OpenRouter, OpenAI, Claude 또는 사용자 지정 엔드포인트), Polishing을 완전히 끌 수도 있고, 실패하면 원본 필사본으로 대체됩니다.

신뢰성

녹음 완료 후 명확한 복구 경로를 제공합니다.

설정된 Polishing 제공사에서 처리 실패

자동으로 원본 필사본으로 대체되며, HUD에 알림이 표시됩니다.

붙여넣을 위치가 포커스되어 있지 않았음

텍스트는 클립보드에 남고, ⌘V를 누르라는 HUD 안내가 표시됩니다.

녹음이 끝난 뒤 앱이 종료됨

Plainsay는 필사 전에 완료된 음성의 임시 저장을 시도합니다. 저장에 성공하면 다음 실행 시 다시 시도할 수 있습니다.

다른 이유로 붙여넣기 실패

기록이 켜져 있으면 Plainsay는 삽입을 시도하기 전에 완료된 필사본을 로컬 기록에 추가합니다.

현재 이용 가능

받아쓰기에 사용하는 언어는 자주 쓰는 순서대로 나열하세요. Whisper가 목록에 없는 언어로 필사한 것이 분명하면 목록의 첫 번째 언어로 다시 시도하고, Parakeet는 그 불일치를 진단 로그에 기록합니다. Cloud 구독자는 Plainsay 메뉴에서 자동 번역을 사용하거나 Control–Option–Command–T로 켜고 끌 수 있습니다. 또한 지원되는 메일 앱과 웹메일 작성 창에서는 이메일 레이아웃이 자동으로 적용됩니다. 번역과 이메일 레이아웃을 사용하려면 Polishing이 활성화되고 설정되어 있어야 합니다.

세 가지 사용 방법

Plainsay Cloud는 필사 모델 다운로드나 API 키 설정이 필요 없습니다. Mac에서 모든 걸 처리하고 싶다면 로컬 모드에서 무료로, 분 또는 단어 수 할당량과 계정 없이 온디바이스 받아쓰기를 사용할 수 있습니다. 호스팅 방식의 음성 인식과 Polishing은 선택 사항입니다.

안내에 따라 설정하고 받아쓰기를 시작하세요.

소요 시간은 선택한 필사 모델의 다운로드에 따라 달라지며, Cloud는 해당 모델이 필요 없습니다.
