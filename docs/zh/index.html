实际界面

开源、透明、安全

在这里，信任不是一句口号：你可以亲自阅读代码。Plainsay Mac 客户端源码以 MIT 许可公开。每个已按 MIT 发布的版本都可以自由复刻、修改和自行构建；第三方组件和模型各有自己的许可证。

开放的部分

Plainsay Mac 客户端源码包括转录和 Polishing 集成、HUD、设置及设置助理。第三方组件和模型保留各自的许可证。Mac 客户端不会发送分析或遥测数据。签名更新检查默认会连接 api.plainsay.app，并可在设置中关闭。可选的 Cloud 会记录运营付费服务所需的账户、订阅和用量元数据。

不开放的部分

付费 Cloud 套餐的后端通过 Stripe 管理订阅状态，保存服务提供商凭证，并记录付费服务所需的账户、订阅和用量元数据。Plainsay Mac 客户端源码开放；可选的 Cloud 服务不开放。

清理步骤会去掉口头禅和重新起头的话，并修正标点。默认情况下，Polishing 会保留措辞、含义、语气和语言；重要文字请复核。开启自动翻译并选择支持样式指令的 BYOK 供应商或兼容的本地 Polishing 供应商后，Polishing 会改为用 Plainsay 菜单中选定的目标语言输出此后每一段新听写。供应商可以更换（Gemini、OpenRouter、OpenAI、Claude 或自定义端点），Polishing 也可以完全关闭；任何处理失败都会回退到原始转录文本。

为什么选择 Plainsay

可靠性

录音完成后有明确的恢复路径。

已配置的 Polishing 供应商处理失败

自动回退到原始转录文本，并在 HUD 中提示。

没有可粘贴的焦点位置

文字会保留在剪贴板中，HUD 会提示按 ⌘V。

录音完成后应用关闭

Plainsay 会尝试在转录前暂存完成的音频。暂存成功后，可在下次启动时重试。

粘贴因其他原因失败

启用历史记录后，Plainsay 会在尝试插入前将完成的转录加入本地历史记录。

现已可用

先选择一种主要听写语言，再添加你使用的其他语言。对于只接受一种语言提示的供应商和模型，Plainsay 会传入主语言。若 Whisper 返回的结果明显使用了未列出的语言，它会改用主语言重试；Parakeet 无法强制重试，因此会将不匹配情况记入诊断日志。Cloud 订阅处于有效状态且 Polishing 已启用并完成配置时，可在 Plainsay 菜单中从你的听写语言或英语中选择自动翻译目标，也可在任何位置按 Control–Option–Command–T 开关上次所选目标的自动翻译。邮件模式默认关闭；在受支持的邮件应用和识别出的网页邮箱撰写窗口中，它可以自动编排问候语、正文段落和结束语。这些样式目前适用于支持样式指令的 BYOK 和兼容的本地 Polishing 供应商；内置的 Plainsay Cloud Polishing 路径尚不会传递翻译或邮件排版指令。
