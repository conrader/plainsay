Código abierto, transparente, seguro

Aquí la confianza no es una afirmación: puedes leer el código. El código fuente del cliente de Plainsay para Mac es público bajo MIT. Cada versión ya publicada bajo MIT sigue siendo libre para crear forks, modificarla y compilarla; los componentes y modelos de terceros tienen sus propias licencias.

LO QUE ES ABIERTO

El código fuente del cliente de Plainsay para Mac incluye sus integraciones de transcripción y Polishing, el HUD, Ajustes y el Asistente de configuración. Los componentes y modelos de terceros conservan sus propias licencias. El cliente de Mac no envía analítica ni telemetría. Las comprobaciones de actualizaciones firmadas contactan con api.plainsay.app por defecto y se pueden desactivar en Ajustes. Cloud opcional registra los metadatos de cuenta, suscripción y uso necesarios para operar el servicio de pago.

LO QUE NO LO ES

El backend del plan Cloud de pago gestiona el estado de la suscripción mediante Stripe, guarda credenciales de los proveedores y registra los metadatos de cuenta, suscripción y uso necesarios para el servicio de pago. El código fuente del cliente de Plainsay para Mac es abierto; el servicio Cloud opcional no.

Tres formas de usarlo

Plainsay Cloud no requiere descargar un modelo de transcripción ni configurar una clave API. ¿Prefieres tenerlo todo en tu Mac? El modo local ofrece dictado completo en el dispositivo, gratis, sin cuotas de minutos ni palabras y sin cuenta; la transcripción alojada y Polishing siguen siendo opcionales.
