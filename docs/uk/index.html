ЩО ВІДКРИТО

Вихідний код клієнта Plainsay для Mac охоплює інтеграції розшифрування та Polishing, HUD, Налаштування й Асистент налаштування. Сторонні компоненти й моделі зберігають власні ліцензії. Клієнт Mac не надсилає аналітику чи телеметрію. Перевірка підписаних оновлень типово звертається до api.plainsay.app і вимикається в Налаштуваннях. Опційний Cloud записує метадані облікового запису, підписки й використання, потрібні для роботи платного сервісу.

ЩО НЕ ВІДКРИТО

Бекенд платного тарифу Cloud керує станом підписки через Stripe, зберігає облікові дані постачальників і записує метадані облікового запису, підписки й використання, потрібні платному сервісу. Вихідний код клієнта Plainsay для Mac відкритий; опційний сервіс Cloud — ні.

Чому Plainsay

Надійність

Зрозумілі шляхи відновлення після завершення запису.

Налаштований постачальник Polishing не спрацював

Автоматичне повернення до необробленої розшифровки з повідомленням у HUD.

Не було обрано місця для вставки

Текст лишається в буфері обміну, з підказкою в HUD натиснути ⌘V.

Застосунок закрився після завершення запису

Plainsay намагається підготувати готове аудіо до розшифрування. Якщо збереження вдалося, обробку можна повторити під час наступного запуску.

Вставка не вдалася з іншої причини

Plainsay додає готову розшифровку до локальної історії перед спробою вставки.

Незабаром

Також: подальша робота над автоматичним визначенням мови та зміни типової моделі в міру вдосконалення локальних моделей.
