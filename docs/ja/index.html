オープンソース、透明、安全

ここでの信頼は主張ではなく、実際にコードを読めることです。Plainsay MacクライアントのソースはMITライセンスで公開されています。すでにMITで公開された各バージョンは自由にフォーク、変更、ビルドできます。サードパーティ製コンポーネントとモデルには個別のライセンスがあります。

公開されているもの

Plainsay Macクライアントのソースには、文字起こしとPolishingの統合、HUD、設定、セットアップアシスタントが含まれます。サードパーティ製コンポーネントとモデルには個別のライセンスがあります。Macクライアントはアクセス解析やテレメトリーを送信しません。署名付きアップデートの確認はデフォルトでapi.plainsay.appへ接続し、設定で無効にできます。オプションのCloudは、有料サービスの運営に必要なアカウント、購読、使用量のメタデータを記録します。

公開されていないもの

有料CloudプランのバックエンドはStripe経由で購読状態を管理し、サービス提供者の認証情報を保持し、有料サービスに必要なアカウント、購読、使用量のメタデータを記録します。Plainsay Macクライアントのソースは公開されていますが、オプションのCloudサービスは公開されていません。

話した言葉が、そのまま文章に

話した内容

えーとつまりあの明日のスタンドアップを10時半くらいに動かせますかね、朝ちょっと歯医者があって

Plainsayが入力した内容

明日のスタンドアップを10時半に動かせますか？朝、歯医者の予約があります。

クリーンアップ処理はフィラーや言い直しを取り除き、句読点を整えます。Polishingには、言葉遣い、意味、トーン、言語を保つよう指示しています。重要な文章は確認してください。プロバイダーは切り替え可能で（Gemini、OpenRouter、OpenAI、Claude、または独自エンドポイント）、完全にオフにすることもでき、失敗した場合は口述筆記自体を失敗させるのではなく、生の文字起こしにフォールバックします。

Plainsayを選ぶ理由

信頼性

録音完了後に明確な復旧手段があります。

設定済みのPolishingプロバイダーで処理に失敗

自動的に生の文字起こしにフォールバックし、HUDに通知が表示されます。

貼り付け先にフォーカスされたものがなかった

テキストはクリップボードに残り、⌘Vを押すよう促すHUD表示が出ます。

録音完了後にアプリが終了

Plainsayは文字起こし前に完成した音声の一時保存を試みます。保存に成功した場合は、次回起動時に再試行できます。

それ以外の理由で貼り付けが失敗

Plainsayは挿入を試みる前に、完了した文字起こしをローカル履歴へ追加します。

今後の予定

また、言語の自動検出への継続的な取り組みと、ローカルモデルの向上に伴うデフォルトモデルの変更も予定しています。

3つの使い方

Plainsay Cloudは文字起こしモデルのダウンロードもAPIキーの設定も不要です。すべてMac上で完結させたい方は、ローカルモードを無料、分数・単語数の利用枠なし、アカウント不要で利用できます。ホスト型の文字起こしとPolishingはオプションです。

ガイド付きセットアップで口述筆記を始められます。

所要時間は選択した文字起こしモデルのダウンロードによって変わります。Cloudならそのモデルは不要です。
