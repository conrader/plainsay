En action

Open source, transparent, sûr

Ici, la confiance n'est pas une promesse : vous pouvez lire le code. Le code source du client Plainsay pour Mac est public sous licence MIT. Chaque version déjà publiée sous MIT reste libre d'être forkée, modifiée et compilée ; les composants et modèles tiers ont leurs propres licences.

CE QUI EST OUVERT

Le code source du client Plainsay pour Mac comprend ses intégrations de transcription et Polishing, le HUD, les Réglages et l'Assistant de configuration. Les composants et modèles tiers conservent leurs propres licences. Le client Mac n'envoie ni analytics ni télémétrie. La vérification des mises à jour signées contacte api.plainsay.app par défaut et peut être désactivée dans les Réglages. Le Cloud optionnel enregistre les métadonnées de compte, d'abonnement et d'usage nécessaires au service payant.

CE QUI NE L'EST PAS

Le backend de l'offre Cloud payante gère l'état de l'abonnement via Stripe, conserve les identifiants des fournisseurs et enregistre les métadonnées de compte, d'abonnement et d'usage nécessaires au service payant. Le code source du client Plainsay pour Mac est ouvert ; le service Cloud optionnel ne l'est pas.

La passe de nettoyage supprime les hésitations et les faux départs et corrige la ponctuation. Par défaut, Polishing préserve la formulation, le sens, le ton et la langue ; relisez les textes importants. Lorsque Auto-translate est activé et qu’un fournisseur BYOK prenant en charge les styles ou un fournisseur local de Polishing compatible est sélectionné, Polishing restitue au contraire chaque nouvelle dictée dans la langue cible choisie dans le menu Plainsay. Le fournisseur est interchangeable (Gemini, OpenRouter, OpenAI, Claude ou un endpoint personnalisé), peut être entièrement désactivé et tout échec entraîne un retour au transcript brut.

Fiabilité

Des voies de récupération claires une fois l'enregistrement terminé.

Un fournisseur de Polishing configuré échoue

Retour automatique au transcript brut, avec un avis dans le HUD.

Rien n'était sélectionné pour coller le texte

Le texte reste dans le presse-papiers, avec une invite du HUD à appuyer sur ⌘V.

L'app se ferme une fois l'enregistrement terminé

Plainsay tente de mettre en attente l'audio terminé avant la transcription. Si cette opération réussit, il peut réessayer au prochain lancement.

Le collage échoue pour toute autre raison

Lorsque l’historique est activé, Plainsay ajoute la transcription terminée à l’historique local avant de tenter l’insertion.

Disponible dès maintenant

Choisissez une langue parlée principale, puis ajoutez toutes les autres que vous utilisez. Les fournisseurs et modèles qui n’acceptent qu’une seule indication de langue reçoivent la langue principale. Si Whisper renvoie manifestement un transcript dans une langue absente de la liste, il réessaie dans la langue principale ; Parakeet consigne l’incohérence, car il ne peut pas imposer une nouvelle tentative. Avec un abonnement Cloud actif et Polishing activé et configuré, choisissez dans le menu Plainsay une langue cible pour Auto-translate parmi vos langues parlées ou l’anglais, ou activez ou désactivez la dernière cible depuis n’importe où avec Control–Option–Command–T. Le mode e-mail est désactivé par défaut et peut mettre automatiquement en forme les salutations, les paragraphes du corps du message et les formules de fin dans les apps de messagerie prises en charge et les fenêtres de rédaction des webmails reconnus. Ces styles fonctionnent actuellement avec les fournisseurs BYOK prenant en charge les styles et les fournisseurs locaux de Polishing compatibles ; la voie de Polishing intégrée à Plainsay Cloud ne transmet pas encore l’instruction de traduction ou de mise en forme des e-mails.

Trois façons de l'utiliser

Plainsay Cloud ne demande ni téléchargement d'un modèle de transcription ni configuration d'une clé API. Vous préférez tout garder sur votre Mac ? Le mode Local offre gratuitement une dictée complète sur l'appareil, sans quota de minutes ni de mots et sans compte ; la transcription hébergée et le Polishing restent facultatifs.

Commencez à dicter avec une configuration guidée.

La durée dépend du téléchargement du modèle de transcription choisi ; Cloud évite ce modèle.
